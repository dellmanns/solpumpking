# Open Model Toolkit (Free Demo)

A simple static web app that runs locally and includes free interactive tools.

## Included tools

- Prompt Refiner
- Nano Banana Pro2 (free brief generator)
- Motion Control 2.6 (free motion preset generator)
- Model Compare (UI concept card)

## Run

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Open <http://localhost:4173>.
